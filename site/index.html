До и после интеграции

Это специально подготовленная небольшая Canvas-игра «Орда на колёсах» в двух состояниях — не опубликованная production-игра и не аудит случайно выбранного проекта. before намеренно содержит типовые проблемы интеграции, а after показывает исправленный вариант.

Результаты не нарисованы и не захардкожены: checker открывается автоматически, а browser audit действительно запускает оба варианта и формирует PASS / FAIL / WARN / NOT VERIFIED.

Before

3 hard FAIL в проверенном browser fixture: нет YaGames.init(), нет LoadingAPI.ready(), не блокируется context menu.

After

0 hard FAIL в browser fixture. Добавлены SDK bootstrap, язык, Game Ready, input gate, lifecycle, mobile hardening и sound toggle.

Важно: Pages-демо использует локальный mock SDK только для показа интеграции вне Яндекс Игр. Production-пример after/index.html использует официальный /sdk.js. Финальную проверку всегда выполняйте на черновике Яндекс Игр.
